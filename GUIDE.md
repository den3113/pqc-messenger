# PQC-Messenger — Полное руководство

Пошаговая инструкция по установке, настройке relay-сервера и обмену сообщениями между двумя пользователями.

---

## 1. Установка

### На каждом устройстве (сервер + все клиенты):

```bash
# Клонировать репозиторий (или скопировать папку проекта)
git clone <url> && cd Individual

# Создать виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate   # Linux/Mac
# .venv\Scripts\activate    # Windows

# Установить проект
pip install -e .

# Или через requirements.txt
pip install -r requirements.txt
```

После установки доступны две команды:
| Команда | Назначение |
|---|---|
| `pqc-server` | Запуск relay-сервера |
| `pqc-client` | Запуск CLI-клиента |

---

## 2. Запуск Relay-сервера

Relay-сервер — это «слепой» ретранслятор. Он **не видит содержимое** сообщений, а только маршрутизирует зашифрованные пакеты между клиентами.

### Сервер нужно запустить **один раз** на одном из устройств:

```bash
# По умолчанию: слушает на 0.0.0.0:8765 (все интерфейсы)
pqc-server
```

Или с явными параметрами:

```bash
pqc-server --host 0.0.0.0 --port 8765 --debug
```

> [!IMPORTANT]
> `0.0.0.0` означает, что сервер принимает подключения **со всех сетевых интерфейсов** — это позволяет другим устройствам в сети подключаться к нему.

### Узнайте IP-адрес машины с сервером:

```bash
# Linux
ip addr show | grep 'inet '
# или
ip -4 -o addr show | grep -v 'lo' | awk '{print $4}'

# Windows
ipconfig
```

Запомните этот IP (например, `192.168.1.100`) — он понадобится клиентам.

## 3. Настройка клиентов

### Сценарий: два пользователя (Алиса и Боб)

```
┌─────────────┐       ws://192.168.1.100:8765       ┌─────────────┐
│   Алиса     │ ────────────────┐  ┌────────────────│    Боб      │
│  (клиент)   │                 │  │                │  (клиент)   │
└─────────────┘                 ▼  ▼                └─────────────┘
                         ┌──────────────┐
                         │ Relay Server │
                         │  (слепой)    │
                         └──────────────┘
```

> [!NOTE]
> Оба клиента можно запустить **на одной машине** (например, в двух терминалах), или на **разных устройствах** в одной сети.

## 4. Пошаговый запуск чата

### Шаг 1 — Запустить relay (в отдельном терминале)

```bash
pqc-server
# Вывод: Relay Server запущен на ws://0.0.0.0:8765
```

---

### Шаг 2 — Запустить клиент Алисы (терминал 2)

```bash
pqc-client
```

```
pqc > /login
Пароль: ********
✓ Новая идентичность создана!
Подтвердите пароль: ********

Ваш ID:
  ABCD-EF01-2345-6789-...
```

---

### Шаг 3 — Получить ключи Алисы

```
pqc > /myid
```

Вывод покажет **компактный формат** в конце — это то, что нужно передать Бобу:

```
Компактный формат (для /add):
  <x25519_hex>:<kyber_hex>
```

> [!TIP]
> Скопируйте компактную строку целиком (это hex-строка вида `aabb...cc:ddee...ff`).

---

### Шаг 4 — Запустить клиент Боба (терминал 3)

```bash
# Если Боб на ТОЙ ЖЕ машине:
pqc-client --data-dir ~/.pqc_messenger_bob

# Если Боб на ДРУГОМ устройстве:
pqc-client
```

> [!WARNING]
> Если два клиента запущены **на одном компьютере**, нужно указать **разные** `--data-dir`, иначе они будут использовать одно и то же хранилище ключей!

```
pqc > /login
Пароль: ********
✓ Новая идентичность создана!
```

---

### Шаг 5 — Обмен ключами (вручную, вне мессенджера)

Алиса и Боб должны передать друг другу свои ключи любым способом (лично, через другой мессенджер и т.д.):

**Боб добавляет Алису:**
```
pqc > /add <компактные_ключи_Алисы>
Имя контакта: Алиса
✓ Контакт добавлен: Алиса [ABCD-EF01-...]
```

**Алиса добавляет Боба:**
```
pqc > /add <компактные_ключи_Боба>
Имя контакта: Боб
✓ Контакт добавлен: Боб [1234-5678-...]
```

---

### Шаг 6 — Подключение к relay

**Если клиент на ТОЙ ЖЕ машине, что и сервер:**
```
pqc > /connect ws://localhost:8765
✓ Подключено к ws://localhost:8765
```

**Если клиент на ДРУГОМ устройстве в сети:**
```
pqc > /connect ws://192.168.1.100:8765
✓ Подключено к ws://192.168.1.100:8765
```

> [!CAUTION]
> `localhost` и `127.0.0.1` работают **только на той же машине**, где запущен сервер. С другого устройства используйте **реальный IP** сервера (например, `192.168.1.100`).

---

### Шаг 7 — Начать чат

```
pqc > /contacts
  1. Алиса [ABCD-EF01-...]

pqc > /chat 1
Чат с Алиса. Вводите сообщения:

[Алиса] > Привет! Это постквантово-защищённое сообщение 🔒
  → Отправлено
```

## 5. Подключение с другого устройства (подробно)

### Проблема: `ws://0.0.0.0:8765` — это **НЕ адрес для подключения!**

`0.0.0.0` — это специальный адрес, означающий «слушать на всех интерфейсах». Клиенты **не могут** подключаться к `0.0.0.0`.

### Решение:

| Ситуация | URL для подключения |
|---|---|
| Клиент на **той же машине** | `ws://localhost:8765` |
| Клиент в **одной Wi-Fi/LAN сети** | `ws://<IP_сервера>:8765` |
| Клиент через **интернет** | Нужен публичный IP или проброс порта |

### Чеклист для подключения другого устройства:

1. **Оба устройства в одной сети** (подключены к одному Wi-Fi роутеру или LAN).

2. **Узнайте IP сервера** (на машине, где запущен `pqc-server`):
   ```bash
   ip addr show | grep 'inet '
   # Пример: 192.168.1.100
   ```

3. **Проверьте, что порт открыт** (на сервере):
   ```bash
   # Убедитесь, что файрвол не блокирует порт 8765
   sudo ufw allow 8765        # Ubuntu
   sudo firewall-cmd --add-port=8765/tcp  # Fedora/CentOS
   ```

4. **Подключитесь с клиента:**
   ```
   pqc > /connect ws://192.168.1.100:8765
   ```

5. **Проверьте соединение** — если не работает:
   ```bash
   # С клиентского устройства проверьте доступность:
   ping 192.168.1.100
   # Проверьте порт:
   python3 -c "import socket; s=socket.socket(); s.settimeout(3); s.connect(('192.168.1.100', 8765)); print('OK'); s.close()"
   ```

## 6. Пример полной сессии (два терминала на одной машине)

### Терминал 1 — Relay:
```bash
source .venv/bin/activate
pqc-server
```

### Терминал 2 — Алиса:
```bash
source .venv/bin/activate
pqc-client
```
```
pqc > /login
Пароль: alice123
pqc > /myid
# Скопировать компактные ключи → передать Бобу
pqc > /add <ключи_Боба>
Имя контакта: Боб
pqc > /connect ws://localhost:8765
pqc > /chat 1
[Боб] > Привет, Боб!
```

### Терминал 3 — Боб:
```bash
source .venv/bin/activate
pqc-client --data-dir ~/.pqc_messenger_bob
```
```
pqc > /login
Пароль: bob456
pqc > /myid
# Скопировать компактные ключи → передать Алисе
pqc > /add <ключи_Алисы>
Имя контакта: Алиса
pqc > /connect ws://localhost:8765
pqc > /chat 1
[Алиса] > Привет, Алиса!
```

## 7. Список команд CLI

| Команда | Описание |
|---|---|
| `/login` | Создать/разблокировать хранилище |
| `/myid` | Показать свой ID и ключи |
| `/add <ключи>` | Добавить контакт |
| `/contacts` | Список контактов |
| `/chat <номер>` | Начать диалог с контактом |
| `/history` | История сообщений в текущем чате |
| `/connect [url]` | Подключиться к relay (по умолчанию `ws://localhost:8765`) |
| `/wipe` | ⚠ Удалить все данные |
| `/help` | Справка |
| `/quit` | Выход |

---

## 8. Частые проблемы

| Проблема | Решение |
|---|---|
| `Сначала выполните /login` | Выполните `/login` перед `/connect` или `/add` |
| `Не удалось подключиться к relay` | Проверьте, что `pqc-server` запущен, и URL корректный |
| `Connection refused` с другого устройства | Используйте IP сервера вместо `localhost`; проверьте файрвол |
| Два клиента используют одни ключи | Укажите разные `--data-dir` при запуске на одной машине |
